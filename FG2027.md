**Status:** code and initial paper draft prepared. Both data audits passed (see PAPER_NOTES.md); no experiments run yet. Core protocol agreed.

**First batch: 22 runs**, using seed **379** (11 combinations × 2 datasets). Additional seeds are deferred.

## Protocol decisions

1. **Pose points — agreed:** follow IberSPEECH's 13 points. Verified: the pose files store COCO body points 0–12 (nose to hips). Expected input sizes: **84 / 110 / 246**. Pose already includes some head/face information.
2. **Positional encoding — agreed:** omit it in the Transformer models, based on the IberSPEECH results and Luna-Jiménez et al. (2025), cited there. No new positional-encoding ablation is planned; this paper focuses on modalities and fusion. The encoder's inability to distinguish reordered frames remains a limitation to acknowledge.
3. **Late fusion — agreed:** train separate encoders together and learn how much each prediction contributes. This uses more parameters; any gains cannot be credited to fusion alone. A size-matched comparison would require extra runs.
4. **Training — agreed:** retain the IberSPEECH settings below. No scheduler or warmup, as neither is specified in the paper; keep the learning rate constant.

## Agreed training settings

| Setting | Value |
|---|---|
| Epochs / batch size | 100 / 32 |
| Optimizer | AdamW; learning rate 0.0001; weight decay 0.01 |
| Learning-rate schedule | None; constant learning rate, no warmup |
| Dropout | 0 |
| Seed — first batch | 379 |
| Model selection | Best validation accuracy; then evaluate test set |
| Reporting | Accuracy, macro-F1, weighted-F1; single-seed scores for now |

Reuse existing models. SPOTER is an adapted baseline, not an exact reproduction.

## Fairness and validation

- Same clips, splits and preprocessing across comparisons; verify source/signer overlap.
- Preserve stored normalization. Align modalities by video and frame ID.
- Keep full sequences. Treat missing landmarks separately from batch padding.
- Frames with several detected people: keep the person closest to the horizontal image centre, for all modalities. Coordinates slightly outside [0,1] are kept unchanged. See [PAPER_NOTES.md](PAPER_NOTES.md).
- Stop on missing clips, duplicate video/frame/person rows, coordinates far outside [0,1] or invalid numerical values.
- Save configurations, seeds, data/code versions, logs, predictions and resumable checkpoints.
- Later: bootstrap saved test predictions for confidence intervals, using paired resamples across models. Check source/signer grouping before choosing the resampling unit.
